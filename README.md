# Wunschbaum

Eine kleine Pinnwand für Geburtstags- und Weihnachtswünsche.
Familienmitglieder als Post-its frei anordnen, verbinden und Wünsche darunter sammeln.

**Live:** siehe GitHub Pages (Settings → Pages)

## Funktionen

- Personen als verschiebbare Post-its, frei verbindbar
- Wünsche pro Person, mit Notiz
- Realistisch / unrealistisch unterscheiden
- Geburtstag / Weihnachten / beides
- Ein Wunsch kann mehreren Personen zugeordnet sein (z. B. "von Papa und Opa")
- PDF-Export zum Ausdrucken
- Backup & Import als JSON

## Wichtig

Die Daten liegen nur im Browser (localStorage) und werden **nicht** zwischen
Geräten synchronisiert. Zum Übertragen: "Backup" auf dem einen Gerät,
"Import" auf dem anderen.

Alles steckt in einer einzigen Datei: `index.html`. Kein Server, keine Abhängigkeiten.
